## Signature

Keep four /api/v1 routes and existing fields. For activation and heartbeat add `nonce`: exactly 32 lowercase hexadecimal chars generated anew for each HTTP send (independent of stable activation request_id). Active replies include `lease_kid` and `lease_signature`. Non-active replies grant nothing and need no signature. Never unsigned-fallback for active. The private signing key exists only server-side, never generated by or bundled with client.

Algorithm RSA-3072 / SHA256 / PKCS#1 v1.5. Public key pinned at build using RSA modulus and exponent (base64) in a generated client source file, not mutable app.config, not fetched from version endpoint. kid = first 16 lowercase hex chars of SHA256(modulus bytes). Only that single pinned kid accepted in this iteration.

Canonical UTF8 message: exactly the following 13 lines joined by LF, no trailing LF:
1. skyeye-lease-v2
2. configured product_id (default CoH3FowTool)
3. active
4. device_id normalized uppercase 64 hex
5. steam_id64 (existing validated decimal text)
6. installation_id normalized Guid D lowercase
7. request nonce as 32 lowercase hex
8. lowercase hex SHA256 of UTF8 effective session_token (64 chars; activation response token, or heartbeat request Bearer if response omits token)
9. server_time signed invariant decimal
10. lease_until signed invariant decimal
11. expires_at signed invariant decimal
12. license_kind exactly permanent or timed
13. lease_kid

Client recomputes from actual request context and reply fields, verifies signature before active lease can be used. Preserve original Gate 0<delta<=60 and request-start monotonic expiry, 28s heartbeat, 1s deduction. Nonce binding prevents replay across fresh requests; do not use request_id as freshness nonce. All decision-bearing active fields above must agree; never trust a signed payload alongside altered visible JSON.
